The pose landmarker model binary (`pose_landmarker_lite.task`, ~5.8MB) is
not committed to git. Fetch it once per environment:

```
curl -o pipeline/models/pose_landmarker_lite.task \
  https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task
```

This is Google's official MediaPipe model asset, not something generated
for this project.
